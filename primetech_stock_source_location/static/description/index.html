Emplacement source par ligne

Un prélèvement précis, fiable et traçable pour chaque opération de stock.

Sélectionnez l’emplacement de prélèvement sur chaque ligne d’un bon de livraison ou d’un transfert interne. Le module utilise ce choix lors de la réservation et de la validation : le stock est réellement prélevé dans l’emplacement sélectionné.

Choix intelligent

Le meilleur emplacement est proposé selon le stock réellement disponible et la quantité demandée.

Périmètre entrepôt

Depuis MAG1/A, choisissez A, B, C et tous leurs sous-emplacements, sans accès aux autres entrepôts.

Contrôle sécurisé

Les règles serveur empêchent les sélections hors entrepôt et les fuites entre sociétés.
